# Análise Avançada de Dados para Tomada de Decisão

Repositório de apoio à disciplina de Análise Avançada de Dados para Tomada de Decisão, ministrada para alunos do 3º semestre do curso de Administração.

## Organização

| Pasta | Conteúdo |
|---|---|
| `temas/` | Um subdiretório por tema, com notas de aula, exemplos e exercícios |
| `notebooks/` | Notebooks em Python ou R, executáveis pelos alunos |
| `dados/` | Bases de dados didáticas em formato CSV |
| `referencias/` | Bibliografia e materiais complementares |

## Temas previstos

1. Correlação (`temas/01-correlacao`)
2. Regressão (`temas/02-regressao`)
3. Análise de clusters (`temas/03-analise-clusters`)

## Como usar

Os notebooks dependem de bibliotecas listadas em `requirements.txt`. Para instalá-las:

```bash
pip install -r requirements.txt
```

O espaço de apoio em Notion, que reúne o mesmo conteúdo de forma navegável, está em *Planejamento de disciplinas*.
